# Runtime source layout

- `core/` — platform, Recovery, theme/debug, loaders and runtime contracts.
- `pedagogy/` — curriculum, Memory, Listening, Scenario, Real Life, Speaking and learner intelligence.
- `ui/` — app shell, responsive/interaction and historical UX compatibility layers still used by runtime.
- `premium/` — Premium visual runtime layers.

Protected root sanctuaries (`app.js`, `voice-ios.js`, `free-voice.js`) stay at repository root.
