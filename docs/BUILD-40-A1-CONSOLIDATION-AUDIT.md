## 1. Executive verdict

French Trân’quille does **not** currently have a content-volume problem at A1.

The curriculum already spans 52 lessons / 313 items and covers a broad practical A1 domain:

- survival and politeness;
- café / restaurant / shopping;
- directions, train, time and appointments;
- health / pharmacy;
- family and social exchange;
- housing / telephone / administration;
- present subject expansion;
- futur proche;
- recent past / passé composé starter patterns;
- questions / negation;
- quantities / comparison;
- invitations / refusal;
- work instructions;
- service problems and transport disruption;
- short narration;
- opinion;
- spoken `on`.

The limiting factor is **depth of productive generalization and trustworthy evidence**, not lack of themes or phrase inventory.

Current product layers prove different things:

```text
curriculum item / challenge
→ taught or recognized in a narrow lesson context

Speaking Loop
→ orally rehearsed / self-compared
→ NOT a durable linguistic score

Listening
→ contextual comprehension / contrast recognition
→ reliable listening miss evidence exists

Scenario Lab
→ guided contextual production against accepted answer sets
→ reliable scenario success/miss/assistance evidence exists

Build38 Transfer
→ explicit deterministic reconstruction of a known structure
→ strongest current direct construction exercise
→ remains ephemeral / no durable transfer evidence owner

Learner Intelligence 3
→ can reliably advise phrase retrieval, listening or scenario practice
→ deliberately cannot infer concept mastery or transfer mastery
```

### Build40 recommendation

**Do not open the A2 implementation roadmap yet.**

The recommended post-audit direction is:

> **A1 Productive Consolidation** — deepen autonomous recombination/construction and improve trustworthy evidence of reuse before adding a new A2 content layer.

This does **not** mean adding dozens of new A1 phrases. It means strengthening the bridge from “I know this sentence” to “I can build a nearby new sentence in context”.

# 2. Evidence model used by this audit

Each capability is classified across these levels:

| Level | Meaning in this audit |
|---|---|
| **Taught / exposed** | Explicit lesson item, grammar note, challenge or Foundation explanation exists. |
| **Rehearsed** | Review / Speaking Loop / lesson challenge can repeat or recall the learned form. |
| **Contextually reused** | Listening or Scenario uses the capability in a real-life context beyond the original lesson. |
| **Constructed / transferred** | A learner must deterministically rebuild a related form rather than merely repeat the stored phrase. |
| **Reliably evidenced** | Current durable observable data can support a pedagogical need decision without invented inference. |
| **Under-evidenced** | Product activity exists, but current durable owners cannot establish concept/generalization mastery. |
| **Missing / deferred** | A structurally useful area has no sufficient explicit treatment yet. |

Important: `knownItems`, lesson completion, a successful speech-recognition transcript, a Scenario completion count or a Speaking Loop recording **do not automatically equal mastery**.

# 5. Build38 construction / transfer depth

Build38 provides the strongest direct evidence that French Trân’quille goes beyond memorized phrases.

Certified learner-facing families:

| Family | Placement | Construction |
|---|---:|---|
| Subject substitution | lesson 33 | change person + rebuild regular verb form |
| Negation | lesson 34 | affirmative → `ne / n’ ... pas` |
| Futur proche | lesson 35 | present action → `aller + infinitive` |
| Nominal number | lesson 13 | singular phrase → plural determiner + noun |
| `nous` → spoken `on` | lesson 52 | rebuild natural spoken equivalent with il/elle-form verb |

Each route uses three deterministic transformations and explicitly avoids claiming mastery.

### Transfer verdict

**High pedagogical quality, narrow family coverage.**

The product proves construction in five useful areas, but many A1 systems remain taught/contextualized without an equivalent generalization tribunal:

- question construction across strategies;
- article / contraction choice beyond nominal plural;
- possessive recombination;
- partitive / quantity recombination;
- past-tense recombination beyond stored blocks;
- adjective agreement across novel noun/adjective pairs;
- narration combining multiple learner-selected events;
- opinion clause recombination.

This is the biggest depth gap before A2.

# 6. Scenario Lab — contextual productive reuse

Scenario system size:

```text
44 situations
132 turns
```

The Scenario engine requires a French response by text or speech-recognition transcript. It records item-level practice through Learning Memory and Error Intelligence using:

```text
scenario-success
scenario-miss
scenario-assisted
```

First miss → hint. Repeated miss → model can be used and assistance is explicitly recorded.

Scenario packs cover survival contexts and later A1 contexts, including:

- café / restaurant / shopping;
- station / train / time;
- pharmacy / health;
- apartment / telephone;
- Jerry / family / social exchange;
- futur proche;
- recent past / passé composé;
- administration;
- emotions;
- natural spoken French;
- reformulation;
- comparison;
- invitation/refusal;
- work instructions;
- housing intervention;
- transport disruption;
- spoken `on`.

Later packs mark many turns as `openResponse:true`, but the Scenario engine still validates against a finite `turn.answers` set. Therefore these are best classified as:

> **guided contextual production**, not unconstrained spontaneous language generation.

### Scenario verdict

Scenario is a **strong A1 consolidation asset** and currently one of the three LI3 families with trustworthy evidence. However, successful Scenario performance does not by itself prove broad grammatical generalization beyond its accepted response families.

# 8. Speaking Loop — oral rehearsal, not mastery evidence

Speaking Loop covers the full 52-lesson curriculum with at most two selected oral moments per lesson.

It can prioritize:

- current lesson phrases;
- challenge answers;
- semantically relevant previously known phrases;
- Memory learning/due/fragile weighting.

The learner can hear Tyffany, record locally, replay her own voice and compare. Audio is temporary and does not become a durable linguistic score.

### Speaking verdict

**Excellent oral rehearsal / self-monitoring layer**, but intentionally not a source of pronunciation or grammatical mastery evidence.

# 11. Gap classification

## 11.1 Content gaps — relatively small

The current A1 thematic range is broad. The clearest explicit structural gap is:

```text
F16 — à / de contractions
```

Other future content refinements may exist, but adding more topics is **not** the primary need.

## 11.2 Construction / generalization gaps — primary pedagogical gap

Current Build38 construction covers only five deterministic families.

Most important under-proven productive systems:

1. **question construction / reformulation** across already taught strategies;
2. **past-time recombination** using known subjects/actions rather than stored blocks;
3. **articles / quantities / contractions** in new noun phrases;
4. **possessive recombination** with known nouns;
5. **adjective agreement** beyond Trân-specific memorized feminine forms;
6. **short narrative assembly** from several known events;
7. **opinion + simple proposition recombination**.

These should be audited for deterministic, vocabulary-safe construction before any broad generator is introduced.

## 11.3 Evidence gaps — equally important

Current product lacks durable trustworthy owners for:

```text
concept understanding
Foundation need / mastery
transfer / construction strength
```

This does **not** mean “add three new localStorage stores”. Any future evidence owner must first justify:

- what observable event it records;
- why that event means something pedagogically;
- how it differs from exposure or recognition;
- rollback / Recovery / backup implications;
- compatibility with existing six-store product truth and seven-store Recovery envelope.

## 11.4 UX/intelligence gaps — secondary

Build39 already gives reliable advisory guidance in Practice. No additional Home/Daily Coach recommendation layer is needed now.

The larger need is pedagogical depth, not another recommendation surface.

# 12. Decision: A1 consolidation vs A1+ vs A2

## Option A — Open A2 now

**Rejected.**

Reason: thematic A1 breadth is already high, while autonomous productive construction and durable concept/transfer evidence remain much narrower. Opening A2 would increase content breadth faster than the product’s ability to prove reusable A1 competence.

## Option B — Create a broad “A1+ content expansion”

**Not selected as the primary direction.**

The audit does not show a major topic shortage. A1+ may become a useful internal label later, but another large phrase/content pack would not address the main weakness.

## Option C — A1 Productive Consolidation

**SELECTED.**

Goal:

> deepen reconstruction, recombination and contextual production using **already taught vocabulary and structures**, while preserving the current conservative evidence model.

This should be treated as a new post-Build40 milestone, not hidden inside Build40 itself.

# 13. Recommended post-Build40 roadmap

The next milestone should be scoped around **A1 Productive Consolidation**, with an audit-first sequence rather than immediate implementation.

Recommended order:

### P1 — Productive-family audit

Audit deterministic, vocabulary-safe construction candidates from existing curriculum. Prioritize:

```text
questions
past-time recombination
articles / quantities / F16 contractions
possessives
adjective agreement
short narration
opinion clauses
```

For each candidate, require:

- source forms genuinely taught;
- target transformation deterministic enough to test;
- no new vocabulary required;
- no semantic ambiguity hidden by a mechanical transform;
- learner placement that does not duplicate the lesson;
- no durable mastery claim by default.

### P2 — F16 decision

F16 should receive a dedicated audit because it is the only explicit `teach-core` Foundation debt still recorded as partial/distributed.

Do not automatically create a capsule until its real curriculum anchors are mapped.

### P3 — Evidence-owner design only after productive events exist

Only after new construction activities produce meaningful observable success/miss/assistance events should the project decide whether a trustworthy concept/transfer evidence owner is justified.

Avoid persistence-first architecture.

### P4 — Re-run A1 audit before A2

A2 can be reconsidered only after productive consolidation has materially widened beyond the five Build38 families and the project can explain what evidence actually changed.
